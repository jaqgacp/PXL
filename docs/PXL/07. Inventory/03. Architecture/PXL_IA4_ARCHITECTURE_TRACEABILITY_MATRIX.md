## 1. Matrix rules

The two status columns use only the required values:

- `Current implementation status` is the repository state at the IA-4 cut-off.
- `Status` is the trace row's current delivery state; it remains non-implemented until
  the named exit phase certifies it.

Abbreviations: `AAS` Architecture Specification; `CS` Costing Specification; `RC`
Reconciliation Contract; `LLS` Layer Lifecycle Specification; `RS` Reporting
Specification; `CDS` Canonical Dataset Specification; `ADR` weighted-average ADR; `HDR`
IA-3 Hardening Decision Register. `PE` means the frozen Posting Engine consumer. Target
logical object names are defined in `PXL_IA4_DATABASE_BLUEPRINT.md`; this matrix does
not prescribe SQL.
